# Domain Docs

This repository uses a single-context layout: `GLOSSARY.md` and `docs/adr/`
at the repository root.

Before exploring, read the root glossary and ADRs relevant to the work. If
either is absent, proceed silently; `/domain-modeling` can create them when
terms or decisions are resolved.

Use the glossary's terms in outputs. If a needed concept is missing, reconsider
the terminology or note the gap for `/domain-modeling`. Explicitly flag proposed
changes that conflict with an existing ADR.
